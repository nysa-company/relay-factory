## Description

Add a zero-dependency Node 18+ command that reads one persisted Relay state
file without starting the service and prints a deterministic,
privacy-minimized inventory of approvals in `blocked_recipient` state. The
report gives operators visibility into safety blocks without exposing a
recipient, subject, body, proposed action, or rejection detail.

This is a read-only projection over Relay's existing durable approval
collection. It does not change the server, persisted schema, worker, approval
behavior, package manifest, or Factory controls.

## Acceptance criteria

1. `node app/tools/blocked-approvals.js <state-file>` prints an
   approval-ID-sorted JSON array containing only each blocked approval's `id`,
   `jobId`, and `proposedAt`.
2. A valid state with no blocked approvals prints `[]` and exits zero.
3. Output never contains recipient, subject, body, action, or rejection-reason
   values, and two invocations are byte-identical.
4. Missing, unreadable, malformed, or structurally invalid input exits nonzero
   with one concise deterministic error and never modifies the state file.
5. Tests are committed before implementation; existing tests are not changed
   or removed.
6. No dependency, server code, persisted schema, package manifest, or Factory
   control changes are permitted.
