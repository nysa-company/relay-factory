## Description

Add a zero-dependency, read-only Node command that counts persisted Relay
outbox entries whose approval identifier and subject exactly match supplied
strings. This supports narrow offline delivery checks without starting Relay
or exposing message bodies.

## Acceptance criteria

1. `node app/tools/outbox-approval-subject-count.js <state-file> <approval-id> <subject>`
   emits compact JSON containing exactly one `outboxWithApprovalAndSubject`
   integer.
2. Approval ID and subject must be non-empty and match stored values exactly
   and case-sensitively; zero matches is valid.
3. Invalid arguments are rejected before file access. Unreadable, malformed,
   or structurally invalid state returns fixed redacted errors; complete
   outbox validation precedes counting.
4. Every invocation is offline, read-only, deterministic, and self-terminating.
5. Tests precede implementation. Targeted, full app, and immutability checks
   pass without dependency, server, schema, manifest, or Factory changes.
