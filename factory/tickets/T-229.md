## Description

Add a zero-dependency, read-only Node command that counts approvals whose action
recipient and body exactly match two operator-supplied strings while offline.

## Acceptance criteria

1. `node app/tools/approval-recipient-body-count.js <state-file> <recipient> <body>`
   emits compact JSON with exactly one `approvalsWithRecipientAndBody` integer.
2. Both strings match exactly without trimming, normalization, or coercion; no
   match emits zero plus one newline.
3. Missing, unreadable, malformed, or structurally invalid state returns fixed
   redacted errors; complete approval validation precedes counting.
4. Every invocation is offline, read-only, deterministic, and self-terminating.
5. Tests precede implementation; targeted, full app, and immutability checks
   pass without dependency, server, schema, manifest, or Factory changes.
