## Description

Add a zero-dependency, read-only Node command that counts persisted Relay
approvals whose job identifier and proposal timestamp exactly match supplied
strings. This supports narrow offline approval checks without starting Relay
or exposing approval bodies.

## Acceptance criteria

1. `node app/tools/approval-job-proposed-count.js <state-file> <job-id> <proposed-at>`
   emits compact JSON containing exactly one `approvalsWithJobAndProposedAt`
   integer.
2. Job ID and proposal timestamp must be non-empty and match stored strings
   exactly and case-sensitively, without timestamp parsing, normalization, or
   coercion; zero matches is valid.
3. Invalid arguments are rejected before file access. Unreadable, malformed,
   or structurally invalid state returns fixed redacted errors; complete
   approval validation precedes counting.
4. Every invocation is offline, read-only, deterministic, and self-terminating.
5. Tests precede implementation. Targeted, full app, and immutability checks
   pass without dependency, server, schema, manifest, or Factory changes.
