## Description

Add a zero-dependency, read-only Node command that selects one event by exact ID
from a persisted Relay state file while the service is offline. It reports only
safe event metadata and never prints the event payload or related job errors.

## Acceptance criteria

1. `node app/tools/event-inspect.js <state-file> <event-id>` exits zero and
   emits deterministic compact JSON with exactly `eventId`, `type`, and
   `receivedAt`.
2. An unknown event ID exits nonzero with one fixed, privacy-safe error.
3. Missing, unreadable, malformed, or structurally invalid state is rejected
   with fixed redacted errors that reveal no path, payload, job error, approval,
   outbox content, or state content.
4. Every invocation is offline, read-only, and self-terminating; input bytes,
   mode, timestamps, and sibling directory entries remain unchanged.
5. Complete acceptance tests are committed before implementation. Targeted,
   full app, and immutability checks pass without dependency, server, schema,
   package-manifest, lockfile, or Factory-control changes.
