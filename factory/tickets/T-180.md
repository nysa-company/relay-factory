## Description

Add a zero-dependency, read-only Node command that selects one approval by
exact ID from a persisted Relay state file while the service is offline. It
reports only safe operational metadata and never prints an approval action,
rejection reason, recipient, subject, body, or outbox content.

Relay can report pending and safety-blocked approval lists offline, but it has
no exact-ID offline approval lookup. This gives an operator that lookup without
starting the service or reading the full persisted record.

## Acceptance criteria

1. `node app/tools/approval-inspect.js <state-file> <approval-id>` exits zero
   and emits deterministic compact JSON with exactly `id`, `jobId`, `status`,
   and `proposedAt`.
2. An unknown approval ID exits nonzero with one fixed, privacy-safe error.
3. Missing, unreadable, malformed, or structurally invalid state is rejected
   with deterministic errors that reveal no input path, payload, parser text,
   approval action, rejection reason, recipient, subject, body, or outbox
   content.
4. Every invocation is offline, read-only, and self-terminating; input bytes,
   mode, timestamps, and sibling directory entries remain unchanged.
5. Complete acceptance tests are committed before implementation. Targeted,
   full app, and immutability checks pass without dependency, server, schema,
   package-manifest, lockfile, or Factory-control changes.
