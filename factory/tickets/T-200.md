## Description

Add a zero-dependency, read-only Node command that counts persisted Relay jobs
whose status exactly matches one operator-supplied value.

## Acceptance criteria

1. `node app/tools/job-status-count.js <state-file> <job-status>` exits zero
   and emits deterministic compact JSON with exactly `jobStatus` and `jobs`.
2. A valid status with no matching jobs returns a `jobs` count of zero.
3. Missing, unreadable, malformed, or structurally invalid state is rejected
   with fixed redacted errors that reveal no path or stored content.
4. Every invocation is offline, read-only, and self-terminating; input bytes,
   mode, timestamps, and sibling directory entries remain unchanged.
5. Complete acceptance tests are committed before implementation. Targeted,
   full app, and immutability checks pass without dependency, server, schema,
   package-manifest, lockfile, or Factory-control changes.
