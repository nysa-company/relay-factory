## Description

Add a zero-dependency, read-only CommonJS command that counts persisted Relay
outbox entries whose approval and job reference an event with a supplied exact
type while Relay is offline.

## Acceptance criteria

1. `node app/tools/outbox-event-type-count.js <state-file> <event-type>` emits
   compact JSON containing exactly one `outboxEntriesForEventType` integer.
2. Type matching is exact and case-sensitive. Every outbox entry must
   reference exactly one valid approval, every referenced approval exactly one
   valid job, and every referenced job exactly one valid event; duplicate IDs,
   duplicate outbox references, and missing references are rejected before
   counting, and zero matches is valid.
3. Invalid arguments are rejected before file access. Unreadable, malformed,
   or structurally invalid state returns fixed redacted errors.
4. The command is offline, zero-dependency, deterministic, read-only, and
   self-terminating. Tests resolve fixtures from the test file, work from any
   current directory, use a five-second child timeout, and do not assume Git
   history depth.
5. Tests precede implementation. Targeted, full app, and immutability checks
   pass without dependency, server, schema, manifest, or Factory changes.
