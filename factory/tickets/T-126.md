## Description

Add `GET /api/events/:id` to the zero-dependency Relay API.

## Acceptance criteria

1. An existing event returns HTTP 200 with exactly its stored event and the
   related job whose `eventId` matches it.
2. An unknown event returns HTTP 404 with the deterministic JSON error
   `{"error":"no such event"}`.
3. The route is read-only and does not change durable state.
4. Tests are committed before implementation; no dependencies or Factory
   controls change.
