## Description

Add a zero-dependency, read-only Node command that counts persisted Relay
events whose payload has one operator-supplied own-property key with one exact
operator-supplied string value while the service is offline.

## Acceptance criteria

1. `node app/tools/event-payload-value-count.js <state-file> <key> <value>`
   exits zero and emits deterministic compact JSON with exactly one
   `eventsWithPayloadValue` nonnegative integer.
2. Matching uses an exact, case-sensitive own-property key and strict string
   value comparison without trimming, coercion, traversal, or prototype
   lookup. No match returns `{"eventsWithPayloadValue":0}` plus one newline.
3. Missing arguments and missing, unreadable, malformed, or structurally
   invalid state are rejected with fixed redacted errors that reveal no path,
   key, value, event ID, type, timestamp, payload, or stored content; complete
   event validation precedes counting.
4. Every invocation is offline, read-only, and self-terminating; input bytes,
   mode, timestamps, and sibling directory entries remain unchanged.
5. Complete acceptance tests are committed before implementation. Targeted,
   full app, and immutability checks pass without dependency, server, schema,
   package-manifest, lockfile, or Factory-control changes.
