## Description

Add a zero-dependency, read-only Node command that counts persisted Relay
approvals whose action subject and status match two supplied strings.

## Acceptance criteria

1. `node app/tools/approval-subject-status-count.js <state-file> <subject> <status>`
   emits compact JSON with exactly one `approvalsWithSubjectAndStatus` integer.
2. Subject matches exactly without trimming, normalization, or coercion; status
   must be `pending`, `sent`, `rejected`, or `blocked_recipient`.
3. Missing arguments, unsupported status, or unreadable, malformed, or
   structurally invalid state returns fixed redacted errors; status is rejected
   before file access and complete approval validation precedes counting.
4. Every invocation is offline, read-only, deterministic, and self-terminating.
5. Tests precede implementation; targeted, full app, and immutability checks
   pass without dependency, server, schema, manifest, or Factory changes.
