## Description

Add a zero-dependency Node command that reads a Relay state file without
starting the service and prints a deterministic report of dead jobs.

## Acceptance criteria

1. `node app/tools/dead-jobs.js <state-file>` prints a job-id-sorted JSON array
   containing only each dead job's `id`, `eventId`, `attempts`, and `retries`.
2. A valid state with no dead jobs prints `[]` and exits zero.
3. Missing, unreadable, malformed, or structurally invalid input exits nonzero
   with a concise deterministic error and never modifies the state file.
4. Tests are committed before implementation; no dependencies, retry action,
   server code, persisted schema, package manifest, or Factory controls change.
