## Description

Add `GET /api/jobs/:id` to the zero-dependency Relay API.

## Acceptance criteria

1. An existing job returns HTTP 200 with exactly its stored job and the
   related event whose `id` matches `eventId`.
2. An unknown job returns HTTP 404 with the deterministic JSON error
   `{"error":"no such job"}`.
3. The route is read-only and does not change durable state.
4. Tests are committed before implementation; no dependencies or Factory
   controls change.
