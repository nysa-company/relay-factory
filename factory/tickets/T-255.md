## Description

Add a zero-dependency, read-only Node command that counts persisted Relay
events whose type matches exactly and whose payload has a supplied own-property
key. This supports narrow offline event checks without starting Relay or
exposing payload values.

## Acceptance criteria

1. `node app/tools/event-type-payload-key-count.js <state-file> <event-type> <payload-key>`
   emits compact JSON containing exactly one `eventsWithTypeAndPayloadKey`
   integer.
2. Event type and payload key must be non-empty strings. Type matching is exact
   and case-sensitive; the key check uses own properties only, without
   trimming, coercion, traversal, or prototype lookup. Zero matches is valid.
3. Invalid arguments are rejected before file access. Unreadable, malformed,
   or structurally invalid state returns fixed redacted errors; complete event
   validation precedes counting.
4. Every invocation is offline, read-only, deterministic, and self-terminating.
5. Tests precede implementation. Targeted, full app, and immutability checks
   pass without dependency, server, schema, manifest, or Factory changes.
