## Description

Add a zero-dependency, read-only Node command that counts persisted Relay
approvals whose job identifier and status exactly match supplied values. This
supports narrow offline approval checks without starting Relay or exposing
approval bodies.

## Acceptance criteria

1. `node app/tools/approval-job-status-count.js <state-file> <job-id> <status>`
   emits compact JSON containing exactly one `approvalsWithJobAndStatus`
   integer.
2. Job ID must be non-empty. Status must exactly equal one Relay approval
   status. Both filters are exact and case-sensitive; zero matches is valid.
3. Invalid arguments are rejected before file access. Unreadable, malformed,
   or structurally invalid state returns fixed redacted errors; complete
   approval validation precedes counting.
4. Every invocation is offline, read-only, deterministic, and self-terminating.
5. Tests precede implementation. Targeted, full app, and immutability checks
   pass without dependency, server, schema, manifest, or Factory changes.
