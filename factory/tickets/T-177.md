## Description

Add a zero-dependency, read-only Node command that selects one event by exact
ID from a persisted Relay state file while the service is offline. It reports
only safe operational metadata and whether a related job exists, without
printing event payloads or approval and outbox content.

Product issue: https://github.com/nysa-company/relay-factory/issues/136

## Acceptance criteria

1. `node app/tools/event-inspect.js <state-file> <event-id>` emits one
   deterministic compact JSON object containing only the selected event's
   `id`, `type`, `receivedAt`, and whether a related job exists.
2. An unknown event ID exits nonzero with one fixed, privacy-safe error.
3. Missing, unreadable, malformed, or structurally invalid state is rejected
   with deterministic errors that reveal no input path, payload, parser text,
   approval action, recipient, subject, body, or outbox content.
4. Every invocation is read-only, offline, and self-terminating; input bytes,
   mode, timestamps, and sibling directory entries remain unchanged.
5. Complete acceptance tests are committed before implementation. Targeted,
   full app, and immutability checks pass without dependency, server, schema,
   package-manifest, lockfile, or Factory-control changes.
