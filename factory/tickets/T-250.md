## Description

Add a zero-dependency, read-only Node command that counts persisted Relay
approvals whose action recipient and subject exactly match supplied strings.
This supports narrow offline approval checks without starting Relay or exposing
approval bodies.

## Acceptance criteria

1. `node app/tools/approval-recipient-subject-count.js <state-file> <recipient> <subject>`
   emits compact JSON containing exactly one `approvalsWithRecipientAndSubject`
   integer.
2. Recipient and subject must be non-empty strings and match stored
   `action.to` and `action.subject` values exactly, without trimming or
   coercion.
3. Invalid arguments are rejected before file access. Unreadable, malformed,
   or structurally invalid state returns fixed redacted errors; complete
   approval validation precedes counting.
4. Every invocation is offline, read-only, deterministic, and self-terminating.
5. Tests precede implementation. Targeted, full app, and immutability checks
   pass without dependency, server, schema, manifest, or Factory changes.
