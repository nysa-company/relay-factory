## Description

Add a zero-dependency, read-only Node command that counts persisted Relay jobs
whose event ID and retry count exactly match supplied values. This supports
narrow offline retry checks without starting Relay or exposing job contents.

## Acceptance criteria

1. `node app/tools/job-event-retry-count.js <state-file> <event-id> <retries>`
   emits compact JSON containing exactly one `jobsWithEventAndRetries` integer.
2. Event ID must be a non-empty string. Retries must use canonical nonnegative
   integer syntax. Both filters must exactly match stored `eventId` and
   integer `retries` values without trimming or coercion.
3. Invalid arguments are rejected before file access. Unreadable, malformed,
   or structurally invalid state returns fixed redacted errors; complete job
   validation precedes counting.
4. Every invocation is offline, read-only, deterministic, and self-terminating.
5. Tests precede implementation. Targeted, full app, and immutability checks
   pass without dependency, server, schema, manifest, or Factory changes.
