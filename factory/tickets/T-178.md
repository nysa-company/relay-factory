## Description

Add a zero-dependency, read-only Node command that selects one job by exact ID
from a persisted Relay state file while the service is offline. It reports only
the operational metadata needed to diagnose the job lifecycle.

Product issue: https://github.com/nysa-company/relay-factory/issues/144

## Acceptance criteria

1. `node app/tools/job-inspect.js <state-file> <job-id>` exits zero and emits
   deterministic compact JSON with exactly `id`, `eventId`, `status`,
   `attempts`, `retries`, and `attemptsSinceRetry`.
2. An unknown job ID exits nonzero with one fixed, privacy-safe error.
3. Unreadable, malformed, or structurally invalid state is rejected with fixed
   redacted errors that reveal no path, payload, or state content.
4. Every invocation is offline, read-only, and self-terminating; input bytes,
   mode, timestamps, and sibling directory entries remain unchanged.
5. Complete acceptance tests are committed before implementation. Targeted,
   full app, and immutability checks pass without dependency, server, schema,
   package-manifest, lockfile, or Factory-control changes.

## Non-goals

No server or HTTP route, schema migration, event payload, `lastError`, approval,
outbox, package, dependency, lockfile, or Factory change is in scope.
