## Description

Add a zero-dependency, read-only Node command that selects one approval by exact
ID from a persisted Relay state file while the service is offline and reports
its safe relationship to a Relay job without printing approval actions,
rejection reasons, event payloads, or job errors.

## Acceptance criteria

1. `node app/tools/approval-job-link.js <state-file> <approval-id>` exits zero
   and emits deterministic compact JSON with exactly `approvalId`, `jobId`,
   `approvalStatus`, and `jobStatus`; `jobStatus` is `null` when no job exists.
2. An unknown approval ID exits nonzero with one fixed, privacy-safe error.
3. Missing, unreadable, malformed, or structurally invalid state is rejected
   with fixed redacted errors that reveal no path, action, rejection reason,
   payload, job error, outbox content, or state content.
4. Every invocation is offline, read-only, and self-terminating; input bytes,
   mode, timestamps, and sibling directory entries remain unchanged.
5. Complete acceptance tests are committed before implementation. Targeted,
   full app, and immutability checks pass without dependency, server, schema,
   package-manifest, lockfile, or Factory-control changes.
