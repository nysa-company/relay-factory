## Description

Operators can count one event type at a time, but cannot obtain a compact
breakdown without repeatedly reading the same state file. Add a zero-dependency
offline command that reports counts for every valid stored event type in one
deterministic result.

## Acceptance criteria

1. `node app/tools/event-type-summary.js <state-file>` exits `0`, writes one
   compact JSON line shaped as `{"eventTypes":[{"type":<stored-type>,"count":N}]}`,
   and writes zero stderr bytes for valid state.
2. Entries are ordered deterministically: strings by code-point order before
   numbers by ascending numeric value. Each distinct string or non-zero finite
   JSON number is counted exactly once; strings and numbers never coerce.
3. Empty input produces `{"eventTypes":[]}`. Repeated invocation is
   byte-for-byte deterministic.
4. Missing or empty types, zero, booleans, objects, arrays, non-finite values,
   invalid event IDs or timestamps, and duplicate event IDs are invalid before
   summarization.
5. Usage, unreadable-file, invalid-JSON, and invalid-state failures use fixed
   redacted one-line stderr messages, the established exit codes, and zero
   stdout bytes. No state contents or paths leak.
6. The command remains offline, zero-dependency, read-only, and
   self-terminating. Tests precede implementation; the targeted test, full app
   suite, and immutability check pass without other product or Factory changes.
