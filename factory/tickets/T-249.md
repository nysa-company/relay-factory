## Description

Add a zero-dependency, read-only Node command that counts persisted Relay
events whose type and received timestamp exactly match supplied strings. This
supports narrow offline event checks without starting Relay or exposing event
payloads.

## Acceptance criteria

1. `node app/tools/event-type-received-count.js <state-file> <event-type> <received-at>`
   emits compact JSON containing exactly one `eventsWithTypeAndReceivedAt`
   integer.
2. Event type and received timestamp must be non-empty strings and match stored
   `type` and `receivedAt` values exactly, without trimming, timestamp parsing,
   normalization, or coercion.
3. Invalid arguments are rejected before file access. Unreadable, malformed,
   or structurally invalid state returns fixed redacted errors; complete event
   validation precedes counting.
4. Every invocation is offline, read-only, deterministic, and self-terminating.
5. Tests precede implementation. Targeted, full app, and immutability checks
   pass without dependency, server, schema, manifest, or Factory changes.
