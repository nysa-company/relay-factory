## Description

Add a zero-dependency, read-only Node command that counts persisted Relay
sandbox outbox entries whose stored `sentAt` value exactly matches one
operator-supplied timestamp while the service is offline.

## Acceptance criteria

1. `node app/tools/outbox-timestamp-count.js <state-file> <timestamp>` exits
   zero and emits deterministic compact JSON with exactly one
   `outboxEntriesAtTimestamp` nonnegative integer.
2. Matching compares stored and supplied strings exactly, without parsing,
   normalization, coercion, or timezone conversion. No exact match returns
   `{"outboxEntriesAtTimestamp":0}` followed by one newline.
3. Missing arguments and missing, unreadable, malformed, or structurally
   invalid state are rejected with fixed redacted errors that reveal no path,
   timestamp, recipient, subject, body, approval ID, or stored content;
   complete outbox validation precedes counting.
4. Every invocation is offline, read-only, and self-terminating; input bytes,
   mode, timestamps, and sibling directory entries remain unchanged.
5. Complete acceptance tests are committed before implementation. Targeted,
   full app, and immutability checks pass without dependency, server, schema,
   package-manifest, lockfile, or Factory-control changes.
