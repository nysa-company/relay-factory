## Description

Add a zero-dependency, read-only Node command that counts persisted Relay jobs
whose event identifier matches exactly and whose attempt count meets a supplied
minimum. This supports narrow offline retry checks without starting Relay or
exposing job payloads.

## Acceptance criteria

1. `node app/tools/job-event-min-attempts-count.js <state-file> <event-id> <minimum-attempts>`
   emits compact JSON containing exactly one
   `jobsWithEventAndMinimumAttempts` integer.
2. Event ID must be non-empty. Minimum attempts must be a canonical
   non-negative decimal integer. Matching is exact and case-sensitive and
   includes jobs with `attempts >= minimum`; zero matches is valid.
3. Invalid arguments are rejected before file access. Unreadable, malformed,
   or structurally invalid state returns fixed redacted errors; complete job
   validation precedes counting.
4. Every invocation is offline, read-only, deterministic, and self-terminating.
5. Tests precede implementation. Targeted, full app, and immutability checks
   pass without dependency, server, schema, manifest, or Factory changes.
