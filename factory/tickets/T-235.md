## Description

Add a zero-dependency, read-only Node command that counts persisted Relay
events whose type and own `payload.to` recipient match two supplied strings.

## Acceptance criteria

1. `node app/tools/event-type-recipient-count.js <state-file> <type> <recipient>`
   emits compact JSON with exactly one `eventsWithTypeAndRecipient` integer.
2. Type and recipient match exact non-empty strings without trimming,
   normalization, coercion, inherited values, or nested-value matching.
3. Missing arguments or unreadable, malformed, or structurally invalid state
   returns fixed redacted errors; complete event validation precedes counting.
4. Every invocation is offline, read-only, deterministic, and self-terminating.
5. Tests precede implementation; targeted, full app, and immutability checks
   pass without dependency, server, schema, manifest, or Factory changes.
