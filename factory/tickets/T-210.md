## Description

Add a zero-dependency, read-only Node command that counts persisted Relay jobs
whose stored `status` exactly matches one operator-supplied value while the
service is offline.

## Acceptance criteria

1. `node app/tools/job-status-count.js <state-file> <status>` exits zero and
   emits deterministic compact JSON with exactly one `jobsWithStatus`
   nonnegative integer.
2. A valid state with no exact status match returns
   `{"jobsWithStatus":0}` followed by one newline.
3. Missing arguments and missing, unreadable, malformed, or structurally
   invalid state are rejected with fixed redacted errors that reveal no path,
   status, job ID, error, event link, or stored content; complete job
   validation precedes counting.
4. Every invocation is offline, read-only, and self-terminating; input bytes,
   mode, timestamps, and sibling directory entries remain unchanged.
5. Complete acceptance tests are committed before implementation. Targeted,
   full app, and immutability checks pass without dependency, server, schema,
   package-manifest, lockfile, or Factory-control changes.
