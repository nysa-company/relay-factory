## Description

Add a zero-dependency Node command that reads a Relay state file without
starting the service and prints deterministic JSON counts for events, jobs by
status, approvals by status, and outbox entries.

## Acceptance criteria

1. `node app/tools/state-summary.js <state-file>` prints one JSON object with
   exact collection and status counts.
2. Output is deterministic and excludes event payloads, approval actions, and
   outbox contents.
3. Missing, unreadable, malformed, or structurally invalid input exits nonzero
   with a concise deterministic error and never modifies the state file.
4. Tests are committed before implementation; no dependencies, server code,
   persisted schema, package manifest, or Factory controls change.
