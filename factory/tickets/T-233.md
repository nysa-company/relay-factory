## Description

Add a zero-dependency, read-only Node command that counts persisted Relay
outbox entries whose recipient and send timestamp match two supplied strings.

## Acceptance criteria

1. `node app/tools/outbox-recipient-timestamp-count.js <state-file> <recipient> <sent-at>`
   emits compact JSON with exactly one `outboxWithRecipientAndTimestamp` integer.
2. Both strings match exactly without trimming, parsing, normalization, or
   coercion; no match emits zero plus one newline.
3. Missing, unreadable, malformed, or structurally invalid state returns fixed
   redacted errors; complete outbox validation precedes counting.
4. Every invocation is offline, read-only, deterministic, and self-terminating.
5. Tests precede implementation; targeted, full app, and immutability checks
   pass without dependency, server, schema, manifest, or Factory changes.
