## Description

Add a zero-dependency, read-only Node command that counts sandbox outbox entries
whose subject and send timestamp exactly match supplied strings. This supports
precise offline receipt reconciliation without exposing bodies or recipients.

## Acceptance criteria

1. `node app/tools/outbox-subject-timestamp-count.js <state-file> <subject> <sent-at>`
   emits compact JSON containing exactly one `outboxWithSubjectAndTimestamp` integer.
2. Subject and timestamp must be non-empty strings and match exactly, without
   trimming, parsing, normalization, coercion, or timezone conversion.
3. Invalid arguments are rejected before file access. Unreadable, malformed,
   or structurally invalid state returns fixed redacted errors; complete outbox
   validation precedes counting.
4. Every invocation is offline, read-only, deterministic, and self-terminating.
5. Tests precede implementation. Targeted, full app, and immutability checks
   pass without dependency, server, schema, manifest, or Factory changes.
