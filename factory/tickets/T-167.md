## Description

Add `GET /api/jobs/:id` to the zero-dependency Relay API using the exact
detail-route and concurrent-ownership decision in
[`factory/rulings.md`](../rulings.md).

## Acceptance criteria

1. An existing job returns HTTP 200 with exactly
   `{"job":<stored job>,"event":<stored related event>}`, where the event's
   `id` equals the job's `eventId`.
2. An unknown job returns HTTP 404 with exactly
   `{"error":"no such job"}`.
3. The route is read-only and does not change durable state.
4. Tests are committed before implementation; no dependencies or Factory
   controls change.
