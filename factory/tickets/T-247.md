## Description

Add a zero-dependency, read-only Node command that counts persisted Relay jobs
whose status and attempt count exactly match supplied values. This supports
narrow offline queue checks without starting Relay or exposing job contents.

## Acceptance criteria

1. `node app/tools/job-status-attempt-count.js <state-file> <status> <attempts>`
   emits compact JSON containing exactly one `jobsWithStatusAndAttempts`
   integer.
2. Status must be one of Relay's three stored job states. Attempts must use
   canonical nonnegative integer syntax. Both filters match stored `status`
   and integer `attempts` values exactly, without trimming or coercion.
3. Invalid arguments are rejected before file access. Unreadable, malformed,
   or structurally invalid state returns fixed redacted errors; complete job
   validation precedes counting.
4. Every invocation is offline, read-only, deterministic, and self-terminating.
5. Tests precede implementation. Targeted, full app, and immutability checks
   pass without dependency, server, schema, manifest, or Factory changes.
