## Description

Add a zero-dependency, read-only Node command that selects one job by exact ID
from a persisted Relay state file while the service is offline. It reports
attempt counters without printing event payloads or job errors.

## Acceptance criteria

1. `node app/tools/job-attempts.js <state-file> <job-id>` exits zero and emits
   deterministic compact JSON with exactly `jobId`, `attempts`, and
   `attemptsSinceRetry`.
2. An unknown job ID exits nonzero with one fixed, privacy-safe error.
3. Missing, unreadable, malformed, or structurally invalid state is rejected
   with fixed redacted errors that reveal no path, event payload, job error,
   approval action, outbox content, or state content.
4. Every invocation is offline, read-only, and self-terminating; input bytes,
   mode, timestamps, and sibling directory entries remain unchanged.
5. Complete acceptance tests are committed before implementation. Targeted,
   full app, and immutability checks pass without dependency, server, schema,
   package-manifest, lockfile, or Factory-control changes.
