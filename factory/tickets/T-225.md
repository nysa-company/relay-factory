## Description

Add a zero-dependency, read-only Node command that counts persisted Relay
events with at least one own payload value that is a string while offline.

## Acceptance criteria

1. `node app/tools/event-payload-string-count.js <state-file>` exits zero and
   emits compact JSON with exactly one `eventsWithPayloadString` integer.
2. Each event contributes at most one; inherited, nested, and non-string values
   do not match. No match returns `{"eventsWithPayloadString":0}` plus newline.
3. Missing, unreadable, malformed, or structurally invalid state returns fixed
   redacted errors; complete event validation precedes counting.
4. Every invocation is offline, read-only, deterministic, and self-terminating.
5. Tests precede implementation; targeted, full app, and immutability checks
   pass without dependency, server, schema, manifest, or Factory changes.
