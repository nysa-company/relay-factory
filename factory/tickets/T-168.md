## Description

Add `GET /api/approvals/:id` to the zero-dependency Relay API using the exact
detail-route and concurrent-ownership decision in
[`factory/rulings.md`](../rulings.md).

## Acceptance criteria

1. An existing approval returns HTTP 200 with exactly
   `{"approval":<stored approval>,"job":<stored related job>}`, where the job's
   `id` equals the approval's `jobId`.
2. An unknown approval returns HTTP 404 with exactly
   `{"error":"no such approval"}`.
3. The route is read-only and does not change durable state.
4. Tests are committed before implementation; no dependencies or Factory
   controls change.
