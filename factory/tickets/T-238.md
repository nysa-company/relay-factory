## Description

Add a zero-dependency, read-only Node command that counts persisted Relay
events whose type and receipt timestamp exactly match supplied strings. This
supports narrow offline event checks without starting Relay or exposing payloads.

## Acceptance criteria

1. `node app/tools/event-type-timestamp-count.js <state-file> <type> <timestamp>`
   emits compact JSON containing exactly one `eventsWithTypeAndTimestamp` integer.
2. Type and timestamp must be non-empty strings and match exactly, without
   trimming, parsing, normalization, coercion, or timezone conversion.
3. Invalid arguments are rejected before file access. Unreadable, malformed,
   or structurally invalid state returns fixed redacted errors; complete event
   validation precedes counting.
4. Every invocation is offline, read-only, deterministic, and self-terminating.
5. Tests precede implementation. Targeted, full app, and immutability checks
   pass without dependency, server, schema, manifest, or Factory changes.
