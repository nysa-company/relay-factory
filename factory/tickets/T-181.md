## Description

Add a zero-dependency, read-only Node command that selects one sandbox outbox
receipt by exact approval ID from a persisted Relay state file while the service
is offline. It reports only safe receipt metadata and never prints the message
recipient, subject, or body.

## Acceptance criteria

1. `node app/tools/outbox-inspect.js <state-file> <approval-id>` exits zero and
   emits deterministic compact JSON with exactly `approvalId` and `sentAt`.
2. An unknown approval ID exits nonzero with one fixed, privacy-safe error.
3. Missing, unreadable, malformed, or structurally invalid state is rejected
   with fixed redacted errors that reveal no path, payload, recipient, subject,
   body, or state content.
4. Every invocation is offline, read-only, and self-terminating; input bytes,
   mode, timestamps, and sibling directory entries remain unchanged.
5. Complete acceptance tests are committed before implementation. Targeted,
   full app, and immutability checks pass without dependency, server, schema,
   package-manifest, lockfile, or Factory-control changes.
