## Description

Add a zero-dependency, read-only Node command that counts persisted Relay jobs
whose event identifier and status exactly match supplied strings. This supports
narrow offline job checks without starting Relay or exposing job errors.

## Acceptance criteria

1. `node app/tools/job-event-status-count.js <state-file> <event-id> <status>`
   emits compact JSON containing exactly one `jobsWithEventAndStatus` integer.
2. Event ID and status must be non-empty and match stored strings exactly and
   case-sensitively, without trimming, normalization, or coercion; zero matches
   is valid.
3. Invalid arguments are rejected before file access. Unreadable, malformed,
   or structurally invalid state returns fixed redacted errors; complete job
   validation precedes counting.
4. Every invocation is offline, read-only, deterministic, and self-terminating.
5. Tests precede implementation. Targeted, full app, and immutability checks
   pass without dependency, server, schema, manifest, or Factory changes.
