## Description

Add a zero-dependency, read-only Node command that counts persisted Relay
outbox entries whose recipient and sent timestamp exactly match supplied
strings. This supports narrow offline delivery checks without starting Relay
or exposing message subjects or bodies.

## Acceptance criteria

1. `node app/tools/outbox-recipient-sent-count.js <state-file> <recipient> <sent-at>`
   emits compact JSON containing exactly one `outboxWithRecipientAndSentAt`
   integer.
2. Recipient and sent timestamp must be non-empty and match stored strings
   exactly and case-sensitively, without timestamp parsing, trimming,
   normalization, or coercion; zero matches is valid.
3. Invalid arguments are rejected before file access. Unreadable, malformed,
   or structurally invalid state returns fixed redacted errors; complete outbox
   validation precedes counting.
4. Every invocation is offline, read-only, deterministic, and self-terminating.
5. Tests precede implementation. Targeted, full app, and immutability checks
   pass without dependency, server, schema, manifest, or Factory changes.
