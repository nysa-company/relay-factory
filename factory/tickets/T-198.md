## Description

Add a zero-dependency, read-only Node command that selects one approval by
exact ID from a persisted Relay state file while the service is offline. It
reports how many stored outbox entries link to that approval without printing
recipient or message content.

## Acceptance criteria

1. `node app/tools/approval-outbox-count.js <state-file> <approval-id>` exits
   zero and emits deterministic compact JSON with exactly `approvalId` and
   `outboxEntries`; zero is a valid count.
2. An unknown approval ID exits nonzero with one fixed, privacy-safe error.
3. Missing, unreadable, malformed, or structurally invalid state is rejected
   with fixed redacted errors that reveal no path, event payload, job error,
   approval action, outbox content, or state content.
4. Every invocation is offline, read-only, and self-terminating; input bytes,
   mode, timestamps, and sibling directory entries remain unchanged.
5. Complete acceptance tests are committed before implementation. Targeted,
   full app, and immutability checks pass without dependency, server, schema,
   package-manifest, lockfile, or Factory-control changes.
