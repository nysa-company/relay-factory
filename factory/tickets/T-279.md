## Description

Add a zero-dependency, read-only CommonJS command that counts persisted Relay
jobs whose status exactly matches a supplied value and whose `lastError` is a
non-empty string while Relay is offline.

## Acceptance criteria

1. `node app/tools/job-status-error-count.js <state-file> <status>` emits
   compact JSON containing exactly one `jobsWithStatusAndError` integer.
2. Status matching is exact and case-sensitive, and a job counts only when
   `lastError` is a string with `.length > 0`; no value is trimmed, normalized,
   case-folded, or coerced, and zero matches is valid.
3. Invalid arguments are rejected before file access. Unreadable, malformed,
   or structurally invalid state returns fixed redacted errors; complete job
   validation precedes filtering and counting.
4. The command is offline, zero-dependency, deterministic, read-only, and
   self-terminating. Tests use a five-second child timeout and prove inputs are
   unchanged.
5. Tests precede implementation. Targeted, full app, and immutability checks
   pass without dependency, server, schema, manifest, or Factory changes.
