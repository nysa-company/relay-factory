## Description

Add a zero-dependency, read-only Node command that counts persisted Relay
approvals whose `reason` is a non-empty string while the service is offline.

## Acceptance criteria

1. `node app/tools/approval-reason-count.js <state-file>` exits zero and emits
   deterministic compact JSON with exactly one `approvalsWithReasons`
   nonnegative integer.
2. A valid state with no approvals carrying a non-empty string `reason`
   returns `{"approvalsWithReasons":0}` followed by one newline.
3. Missing, unreadable, malformed, or structurally invalid state is rejected
   with fixed redacted errors that reveal no path, rejection reason, approval
   action, or stored content; complete approval validation precedes counting.
4. Every invocation is offline, read-only, and self-terminating; input bytes,
   mode, timestamps, and sibling directory entries remain unchanged.
5. Complete acceptance tests are committed before implementation. Targeted,
   full app, and immutability checks pass without dependency, server, schema,
   package-manifest, lockfile, or Factory-control changes.
