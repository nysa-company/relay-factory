## Description

Add a zero-dependency, read-only Node command that counts persisted Relay
approvals whose `action.to` recipient and status match two supplied strings.

## Acceptance criteria

1. `node app/tools/approval-recipient-status-count.js <state-file> <recipient> <status>`
   emits compact JSON with exactly one `approvalsWithRecipientAndStatus` integer.
2. Both strings match exactly without trimming, normalization, or coercion;
   status must be `pending`, `sent`, `rejected`, or `blocked_recipient`.
3. Missing arguments, an unsupported supplied status, or unreadable, malformed,
   or structurally invalid state returns fixed redacted errors; an unsupported
   status is rejected before file access and complete validation precedes counting.
4. Every invocation is offline, read-only, deterministic, and self-terminating.
5. Tests precede implementation; targeted, full app, and immutability checks
   pass without dependency, server, schema, manifest, or Factory changes.
