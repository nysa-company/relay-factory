## Description

Add a zero-dependency, read-only Node command that counts persisted Relay jobs
with one exact status and at least a supplied number of attempts while offline.

## Acceptance criteria

1. `node app/tools/job-status-min-attempts-count.js <state-file> <status> <minimum>`
   emits compact JSON with exactly one `jobsWithStatusAndMinimumAttempts` integer.
2. Status is exactly `pending`, `done`, or `dead`; minimum is a canonical
   non-negative integer, and both filters must match each counted job.
3. Missing or invalid arguments are rejected before file access. Unreadable,
   malformed, or structurally invalid state returns fixed redacted errors;
   complete job validation precedes counting.
4. Every invocation is offline, read-only, deterministic, and self-terminating.
5. Tests precede implementation; targeted, full app, and immutability checks
   pass without dependency, server, schema, manifest, or Factory changes.
