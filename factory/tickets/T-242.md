## Description

Add a zero-dependency, read-only Node command that counts persisted Relay events
whose ID and type exactly match supplied strings. This supports narrow offline
event checks without starting Relay or exposing payloads.

## Acceptance criteria

1. `node app/tools/event-id-type-count.js <state-file> <event-id> <type>` emits
   compact JSON containing exactly one `eventsWithIdAndType` integer.
2. Event ID and type must be non-empty strings and match the stored `id` and
   `type` values exactly, without trimming, parsing, normalization, or coercion.
3. Invalid arguments are rejected before file access. Unreadable, malformed,
   or structurally invalid state returns fixed redacted errors; complete event
   validation precedes counting.
4. Every invocation is offline, read-only, deterministic, and self-terminating.
5. Tests precede implementation. Targeted, full app, and immutability checks
   pass without dependency, server, schema, manifest, or Factory changes.
