## Description

Add a zero-dependency, read-only CommonJS command that counts persisted Relay
approvals whose referenced job has a supplied exact status while Relay is
offline.

## Acceptance criteria

1. `node app/tools/approval-job-status-count.js <state-file> <job-status>`
   emits compact JSON containing exactly one `approvalsForJobStatus` integer.
2. Status matching is exact and case-sensitive. Every approval must reference
   exactly one valid job; duplicate job or approval IDs and missing references
   are rejected before counting, and zero matches is valid.
3. Invalid arguments are rejected before file access. Unreadable, malformed,
   or structurally invalid state returns fixed redacted errors.
4. The command is offline, zero-dependency, deterministic, read-only, and
   self-terminating. Tests resolve fixtures from the test file, work from any
   current directory, use a five-second child timeout, and do not assume Git
   history depth.
5. Tests precede implementation. Targeted, full app, and immutability checks
   pass without dependency, server, schema, manifest, or Factory changes.
