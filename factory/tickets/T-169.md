## Description

Add `GET /api/outbox/:approvalId` to the zero-dependency Relay API using the
exact detail-route and concurrent-ownership decision in
[`factory/rulings.md`](../rulings.md).

## Acceptance criteria

1. An existing outbox item returns HTTP 200 with exactly
   `{"sandbox":true,"receipt":<stored outbox item>}`.
2. An unknown approval ID returns HTTP 404 with exactly
   `{"error":"no such outbox receipt"}`.
3. The route is read-only, explicitly identifies the outbox as sandboxed, and
   never performs an external send.
4. Tests are committed before implementation; no dependencies or Factory
   controls change.
