## Description

Add a zero-dependency, read-only Node command that counts persisted Relay jobs
whose stored `attemptsSinceRetry` integer is greater than zero while the
service is offline. Each matching job contributes one, regardless of count.

## Acceptance criteria

1. `node app/tools/job-attempt-window-count.js <state-file>` exits zero and
   emits deterministic compact JSON with exactly one
   `jobsAttemptedSinceRetry` nonnegative integer.
2. A valid state with no positive `attemptsSinceRetry` value returns
   `{"jobsAttemptedSinceRetry":0}` followed by one newline; attempt values
   are never summed.
3. Missing, unreadable, malformed, or structurally invalid state is rejected
   with fixed redacted errors that reveal no path, job ID, event link, status,
   counters, error, approval, outbox content, or stored content; complete job
   validation precedes counting.
4. Every invocation is offline, read-only, and self-terminating; input bytes,
   mode, timestamps, and sibling directory entries remain unchanged.
5. Complete acceptance tests are committed before implementation. Targeted,
   full app, and immutability checks pass without dependency, server, schema,
   package-manifest, lockfile, or Factory-control changes.
