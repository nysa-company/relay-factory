## Description

Add a zero-dependency Node command that reads a Relay state file without
starting the service and prints a deterministic report of pending approvals.

## Acceptance criteria

1. `node app/tools/pending-approvals.js <state-file>` prints an
   approval-id-sorted JSON array containing only each pending approval's `id`,
   `jobId`, and `proposedAt`.
2. A valid state with no pending approvals prints `[]` and exits zero; output
   never contains recipients, subjects, bodies, or rejection reasons.
3. Missing, unreadable, malformed, or structurally invalid input exits nonzero
   with a concise deterministic error and never modifies the state file.
4. Tests are committed before implementation; no dependencies, approval
   action, server code, persisted schema, package manifest, or Factory controls
   change.
